# 🚆 Sistema Integrado de Transporte - Lima

## 📌 Descripción

Sistema de consola desarrollado en **Swift** para consultar información del sistema de transporte de Lima, incluyendo la **Línea 1, Línea 2 y Metropolitano**, con funcionalidades orientadas a la planificación de viajes y a la consulta de estaciones relacionadas con los **Juegos Panamericanos**.

## ⚙️ Funcionalidades

- 🚆 Consulta de estaciones de la **Línea 1, Línea 2 y Metropolitano**.
- 📍 Consulta detallada de estaciones.
- 🔎 Búsqueda de estaciones por:
  - Nombre exacto.
  - Alias.
  - Coincidencia parcial.
  - Texto normalizado sin considerar tildes.
- ♿ Consulta de información de accesibilidad mediante ascensores.
- 🛣️ Visualización de vías cercanas a determinadas estaciones.
- 🔄 Consulta de conexiones registradas.
- 🧭 Planificación de viajes entre estaciones.
- 🚉 Cálculo de cantidad de estaciones entre origen y destino cuando pertenecen a la misma línea.
- 🗺️ Generación de la ruta entre estaciones de una misma línea.
- ⏱️ Cálculo de tiempo estimado de viaje.
- 🔄 Identificación de viajes que requieren transbordo.
- 💳 Cálculo de tarifa estudiantil o general.
- 🏆 Consulta de sedes relacionadas con los Juegos Panamericanos.
- 📋 Visualización de todas las estaciones disponibles agrupadas por línea.
- 🗺️ Acceso mediante enlace a un mapa del Metro de Lima.
- ℹ️ Visualización de información general del sistema.
- 🎮 Menú principal interactivo mediante consola.
- ❌ Validación de opciones ingresadas por el usuario.

## 🛠️ Tecnologías utilizadas

- Aplicación de consola / Terminal
- Arrays

- Optional

## 📚 Estructura del sistema

El proyecto está organizado en las siguientes secciones:

1. Modelo de datos de las estaciones.
2. Estaciones de la Línea 1.
3. Estaciones de la Línea 2.
4. Estaciones del Metropolitano.
5. Datos generales del sistema.
6. Funciones auxiliares y normalización de texto.
7. Búsqueda de estaciones.
8. Búsqueda de líneas.
9. Consulta de estaciones por línea.
10. Detalle de estaciones.
11. Obtención de rutas.
12. Cálculo de estaciones.
13. Cálculo de tiempo.
14. Cálculo de tarifas.
15. Planificador de viajes.
16. Visualización de estaciones disponibles.
17. Consulta de sedes Panamericanas.
18. Buscador interactivo.
19. Información del sistema.
20. Acceso al mapa.
21. Menú principal interactivo.
